FOREX AI ASSISTANT PRO - XAUUSD LIVE DASHBOARD

สิ่งที่มีในชุดนี้
- forex_ai_pro.py: Dashboard สีเข้มพร้อมกราฟแท่งเทียน M5 และ EMA20/50/200
- forex_ai_assistant.py: เครื่องคำนวณอินดิเคเตอร์/กฎสัญญาณจากโปรเจกต์เดิม
- install_requirements.bat: ติดตั้ง MetaTrader5, Matplotlib และ PyInstaller
- build_exe.bat: สร้าง Windows EXE บนเครื่อง Windows

วิธีทดลองก่อนสร้าง EXE
1. ติดตั้ง Python 3.11 หรือเวอร์ชันที่ MetaTrader5 package รองรับ และเลือก Add Python to PATH
2. เปิด MT5 แล้วล็อกอินบัญชี Demo ให้มีกราฟ XAUUSD และข้อมูลราคา
3. ดับเบิลคลิก install_requirements.bat และรอจนจบ
4. ดับเบิลคลิก เปิด_ForexAI_PRO.bat
5. กด วิเคราะห์ตอนนี้ หรือเปิด อัปเดตอัตโนมัติ

วิธีสร้าง EXE
1. ดับเบิลคลิก build_exe.bat
2. เมื่อเสร็จ เปิด dist\ForexAI_PRO\ForexAI_PRO.exe
3. หากส่งให้ผู้อื่น ให้ส่งทั้งโฟลเดอร์ dist\ForexAI_PRO ไม่ใช่เฉพาะ EXE

ข้อจำกัด/ความปลอดภัย
- ต้องมี MetaTrader 5 desktop เปิดอยู่และเชื่อมต่อบัญชีเองก่อนใช้งาน
- กราฟและสัญญาณอัปเดตจากข้อมูล MT5; ใช้แท่งที่ปิดแล้วในการวิเคราะห์ ส่วน Bid/Ask เป็นราคาปัจจุบัน
- สัญญาณเป็นกฎทางเทคนิคเพื่อประกอบการตัดสินใจ ไม่ใช่คำแนะนำการลงทุนที่รับประกันผล
- โปรแกรมนี้ไม่ส่ง แก้ไข หรือปิดคำสั่งซื้อขาย
- ทดสอบบนบัญชี Demo ก่อนเสมอ; สัญลักษณ์ทองของแต่ละโบรกเกอร์อาจต่างกัน เช่น XAUUSD หรือ GOLD
